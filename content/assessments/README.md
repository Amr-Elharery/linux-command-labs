# Final Assessment

The web portal reads [`final-assessment.json`](final-assessment.json) as the structured source for the six-section Linux Labs Final Assessment. It uses the course's existing five stages and `playground/` fixtures. It is an original Linux Labs assessment, not an additional activity claimed from the supplied course.

## Sections and points

| Section | Focus | Points |
|---|---|---:|
| A | Command fundamentals and syntax | 15 |
| B | File system operations | 10 |
| C | File content inspection and search | 15 |
| D | Text processing and pipelines | 30 |
| E | System information and resource investigation | 10 |
| F | Integrated practical investigation | 20 |
| **Total** | | **100** |

Pass with at least **75/100** and at least **50% of the available points in every section**. Tasks labeled browser-checked compare a typed response with accepted answers; this does not prove a command was run. The practical tasks award learner-reported points only after each rubric item is confirmed. The app does not run shell commands or inspect the learner's machine.

Hints are optional. Explanations and example commands remain collapsed until the task has been submitted or self-assessed. Draft responses save in the browser and can be resumed. Completed attempts are retained locally for review and further attempts.

Initialize synthetic data before the hands-on tasks using the instructions in [`docs/PLAYGROUND.md`](../../docs/PLAYGROUND.md). Practice and reset only within the marked `playground/projects/organization-lab/` disposable workspace. The integrated section is read-only.

The source course count still says 31 guided labs plus 10 challenges, but the supplied material does not enumerate all 41 items or classify every headline. See [`docs/COURSE_MAPPING.md`](../../docs/COURSE_MAPPING.md). This authored assessment does not fill that source-data gap.
